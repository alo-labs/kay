# Milestone v0.9.5 Requirements Archive

**Status:** ✅ SHIPPED 2026-05-16

## v1 Requirements

### Branding

- [x] **BRAND-01**: User-facing docs, help text, and UI copy use `kay`
  branding when they refer to the Kay product.  
  Outcome: validated by the phase 8 docs sweep and the docs index governance
  links.
- [x] **BRAND-02**: Kay-owned navigation, README content, and release-facing
  text stop presenting `codex` or product-branded `code` as the primary brand.  
  Outcome: validated by the docs sweep and the Kay-first landing page.

### Compatibility

- [x] **COMP-01**: Script, binary, workspace, and environment-name changes
  preserve existing launch and build workflows through aliases or phased
  transitions.  
  Outcome: validated by the phase 9 runtime/path sweep and the preserved
  compatibility wrappers.
- [x] **COMP-02**: Protocol, schema, generated-artifact, and package identifiers
  keep legacy names only when required by external consumers or upstream
  comparison.  
  Outcome: validated by the phase 10 boundary audit and compatibility
  inventory.

### Sync and Validation

- [x] **SYNC-01**: A living rename inventory is maintained and updated as
  migration decisions are made.  
  Outcome: validated by the docs sweep and the phase 10 inventory expansion.
- [x] **SYNC-02**: Daily upstream reconciliation keeps common-file drift small
  and records manual rename decisions.  
  Outcome: validated by the migration policy and boundary audit notes.
- [x] **SYNC-03**: Every rename batch passes `./build-fast.sh` and the targeted
  regression checks relevant to the touched surface.  
  Outcome: validated by phase 10 build and regression runs.
