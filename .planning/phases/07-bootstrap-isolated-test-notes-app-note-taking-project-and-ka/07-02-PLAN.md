<objective>
Add a lightweight, modern transcript viewer that turns Kay's JSONL session logs into a readable chat-like review surface.

Purpose: The phase needs an accessible provenance viewer so future model runs and release triage can inspect what happened without spelunking raw JSONL.
Output: A viewer entry point, rendering component, and regression tests that prove the transcript can be reviewed cleanly.
</objective>

<threat_model>
Potential threats:
- A transcript viewer can accidentally expose secrets or other sensitive text if it renders raw payloads without care.
- A read-only viewer can still mutate state if it reuses the wrong interactive code paths.
- If the viewer is not lightweight, it becomes too heavy to use during release triage.
</threat_model>
