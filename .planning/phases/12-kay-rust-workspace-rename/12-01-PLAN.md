# 12-01 Plan: Rename Active Rust Workspace Path

## Goal

Move the active Kay Rust workspace from `code-rs/` to `kay-rs/` without
changing Rust crate identities, imports, binary compatibility, generated
protocol names, or upstream mirror behavior.

## Implementation

1. Start from a clean worktree and remove transient ignored build artifacts.
2. Use `git mv code-rs kay-rs`.
3. Update first-party scripts, root package scripts, release tooling, GitHub
   workflows, upstream comparison scripts, source tests, and active docs to
   reference `kay-rs/` for Kay-owned workspace paths.
4. Preserve selector compatibility in `build-fast.sh`: `kay` and `kay-rs` are
   primary Kay selectors; `code` and `code-rs` remain aliases that resolve to
   `kay-rs/`.
5. Keep `codex-rs/` untouched as the read-only upstream mirror.
6. Do not create a tracked or generated `code-rs -> kay-rs` symlink.

## Verification

Run the path audit, required build, selector compatibility checks, focused
script checks, upstream verification, TypeScript SDK tests, and the full
pre-release gate before pushing to `main`.
