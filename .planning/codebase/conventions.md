# Conventions

## Summary

The repo already has a strong operating contract. Preserve it rather than replacing it.

## Important Conventions

- Use `apply_patch` for manual file edits
- Never run destructive git commands in normal work
- Treat `./build-fast.sh` as the required completion check
- Do not run `rustfmt` unless explicitly requested
- Keep repo instructions in `CLAUDE.md` and Silver Bullet enforcement in `silver-bullet.md`

## Docs Convention

- Existing docs stay intact
- New governance docs are added alongside them
- Monthly knowledge and lessons files remain append-only
